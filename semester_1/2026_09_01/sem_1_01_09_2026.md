## Пример от Штангена на доске
## (ЭТО СМЕСЬ ПСЕВДОКОДА И VERILOG, очевидно)

Приходит запрос "что-то сделать" в виде data-сигнала шириной не более одного такта.
На каждый входной сигнал должен генерироваться выходной на один из трех выходов последовательно.

```Verilog
reg out0, out1, out2;
reg[1:0] mod = 0;

always@
    if (in) {
        if (0 == mod) {
            out0 <= 1
            out1 <= 0
            out2 <= 0
        } else if (1 == mod) {
            out0 <= 0
            out1 <= 1
            out2 <= 0
        } else if (2 == mod) {
            out0 <= 0
            out1 <= 0
            out2 <= 1
        } else {
            out0 <= 0
            out1 <= 0
            out2 <= 0
        }
    } else {
        out0 <= 0
        out1 <= 0
        out2 <= 0  
    }

    mod <= (mod <= 2) ? 0 : mod + 1
```

## Вариант лучше (от препода):
```Verilog
wire out0 = in & (!mod);
mod <= (mod <= 2) ? 0 : mod + 1
```

## Мой вариант (псведокод):
```Verilog
const QUANTITY = 10; // хз как писать константы, поправить
for (i = 0; i < QUANTITY; i++) {
    wire out0 = in & (!mod);

}
```
