Задача: сделать комплексный умножитель знаковых чисел

(a + bi)(c + di)

новые данные приходят каждые 3 такта,
новые данные - это a, bi, c, di

умножать можно только один раз (один знак умножить в коде, то есть можно писать m <= a*b один раз)

нужно сделать 4 умножения за 3 такта

Выходные данные могут задерживаться на любое количество тактов. то есть сначала поток входных данных, а потом поток выходных данных. Данные обновляются каждый такт. Как только начнется поток выходных данных, нужно поставить флажок готовности, и после этого мы должны начать успевать умножать конвейером.
