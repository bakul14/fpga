Задача: быстрый умножитель

y(n+1) = 3y(n) + 2x(n) - это уравение БИХ-фильтра

умножители плохие и занимают 2 такта, но новые данные поступают каждый такт

Выходные данные могут задерживаться на любое количество тактов. то есть сначала поток входных данных, а потом поток выходных данных. Данные обновляются каждый такт. Как только начнется поток выходных данных, нужно поставить флажок готовности, и после этого мы должны начны успеват (то есть задержка может быть любой)

двухтактный умножитель желательно написать отдельным модулем, чтобы было видно, что выход через 2 такта.
